## Findings

The public generator entry point is `auto_generate_system_tools_from_tables`, which requires at least one table name, resolves table metadata into `ToolDataset` objects, and delegates to `_auto_generate_system_tools` with the requested namespace and max result limit (`src/fenic/api/mcp/_tool_generation_utils.py:56`, `src/fenic/api/mcp/_tool_generation_utils.py:67`, `src/fenic/api/mcp/_tool_generation_utils.py:69`). The generated system-tool set is assembled as six `SystemTool` objects: Schema, Profile, Read, Search Summary, Search Content, and Analyze (`src/fenic/api/mcp/_tool_generation_utils.py:99`, `src/fenic/api/mcp/_tool_generation_utils.py:100`, `src/fenic/api/mcp/_tool_generation_utils.py:108`, `src/fenic/api/mcp/_tool_generation_utils.py:120`, `src/fenic/api/mcp/_tool_generation_utils.py:131`, `src/fenic/api/mcp/_tool_generation_utils.py:140`, `src/fenic/api/mcp/_tool_generation_utils.py:150`). Search Summary is a one-argument generated callable whose `pattern` parameter is annotated as a regex pattern with `(?i)` case-insensitive guidance (`src/fenic/api/mcp/_tool_generation_utils.py:268`, `src/fenic/api/mcp/_tool_generation_utils.py:269`). For each dataset, it loads the table as a DataFrame, selects columns whose schema field data type equals `StringType`, ORs together `col(c_name).rlike(pattern)` predicates across those string columns, filters the DataFrame, counts matching rows, and returns an in-memory two-column result with `dataset` and `total_matches` (`src/fenic/api/mcp/_tool_generation_utils.py:272`, `src/fenic/api/mcp/_tool_generation_utils.py:273`, `src/fenic/api/mcp/_tool_generation_utils.py:274`, `src/fenic/api/mcp/_tool_generation_utils.py:278`, `src/fenic/api/mcp/_tool_generation_utils.py:280`, `src/fenic/api/mcp/_tool_generation_utils.py:281`, `src/fenic/api/mcp/_tool_generation_utils.py:283`, `src/fenic/api/mcp/_tool_generation_utils.py:284`, `src/fenic/api/mcp/_tool_generation_utils.py:287`, `src/fenic/api/mcp/_tool_generation_utils.py:288`). Datasets with no string columns contribute a zero-count row without building a predicate (`src/fenic/api/mcp/_tool_generation_utils.py:274`, `src/fenic/api/mcp/_tool_generation_utils.py:275`, `src/fenic/api/mcp/_tool_generation_utils.py:276`).

Search Content is a generated callable for one dataset at a time, with annotated parameters for `df_name`, `pattern`, `limit`, `offset`, `order_by`, `sort_ascending`, and `search_columns` (`src/fenic/api/mcp/_tool_generation_utils.py:318`, `src/fenic/api/mcp/_tool_generation_utils.py:319`, `src/fenic/api/mcp/_tool_generation_utils.py:320`, `src/fenic/api/mcp/_tool_generation_utils.py:321`, `src/fenic/api/mcp/_tool_generation_utils.py:322`, `src/fenic/api/mcp/_tool_generation_utils.py:323`, `src/fenic/api/mcp/_tool_generation_utils.py:325`, `src/fenic/api/mcp/_tool_generation_utils.py:326`).
